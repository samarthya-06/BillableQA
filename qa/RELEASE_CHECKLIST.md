# Learning release checklist

- [ ] App starts using README instructions.
- [ ] Demo login, registration and logout manually checked.
- [ ] All P1 manual cases executed; real results recorded.
- [ ] API suite executed; output and environment recorded.
- [ ] Browser suite executed or clearly marked NOT RUN.
- [ ] Invalid submissions verified to create zero database rows.
- [ ] Duplicate action creates exactly one row.
- [ ] Employee ownership and project permissions checked.
- [ ] Billing values and refresh persistence checked.
- [ ] Real defects triaged; critical/high defects resolved and re-tested.
- [ ] Basic regression completed after final fixes.
- [ ] Database, sessions, environment files and real credentials excluded from Git.
- [ ] Known limitations and remaining risks explained.

Unchecked boxes are not claims of completion. This local learning app is not production certified.
